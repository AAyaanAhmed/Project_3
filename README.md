Expense Tracker

Overview
Expense Tracker is a Python application that helps users manage daily expenses, organize them into categories, set monthly budgets, and monitor spending. All records are stored locally in a JSON file for easy access.

Features
- Add, view, and delete expenses
- Categorize transactions
- Set monthly budgets
- Generate spending summaries
- Search expense records
- Store data using JSON

Technologies
- Python
- JSON
- datetime

Project Structure
Expense-Tracker/
- main.py
- expenses.json
- README.md

How to Run
1. Clone or download the project.
2. Open the project folder in VS Code or PyCharm.
3. Run the application:
project_3.py

Learning Outcomes
This project demonstrates Python programming using functions, file handling, dictionaries, lists, exception handling, and date processing while building a simple personal expense management system.
